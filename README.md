# Тетрис

Небольшая игра, которая работает в браузере без интернета и установки библиотек.

## Установка в Linux Mint

Откройте терминал в папке проекта и выполните:

```bash
./install.sh
```

После установки найдите **Тетрис** в меню приложений. Игра и значок устанавливаются только для текущего пользователя. Для запуска вручную можно открыть `index.html` в браузере.

## Управление

- `←` / `→` или `A` / `D` — двигать фигуру.
- `↑` или `W` — повернуть.
- `↓` или `S` — ускорить падение.
- `Пробел` — сбросить фигуру вниз.
- `P` — пауза.
